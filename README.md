# Ebrahim Adel — Portfolio

Professional personal portfolio inspired by Figma’s product-site language: bold brand typography, layered canvas visuals, high-contrast CTAs, and restrained motion.

## Stack

- React 19 + TypeScript
- Vite
- Framer Motion
- Custom CSS (design tokens, no UI kit)

## Run locally

```bash
cd ebrahim-adel-portfolio
npm install
npm run dev
```

## Customize

Edit `src/data/content.ts` for name, projects, experience, skills, and contact links.

## Build

```bash
npm run build
npm run preview
```
